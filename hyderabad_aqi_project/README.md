# Hyderabad AQI Analysis & Forecasting

End-to-end machine-learning pipeline that preprocesses air-quality data for Hyderabad, performs exploratory analysis, trains and evaluates multiple regression models, produces a 30-day AQI forecast, and exposes everything through an interactive Streamlit dashboard.

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the full pipeline

```bash
python HaleemaSadiya_hydaqi.py
```

This executes all six steps in order:

| Step | What it does |
|------|--------------|
| `preprocess` | Filters Hyderabad rows, interpolates missing values, engineers lag/rolling features |
| `eda` | Generates 6 exploratory figures (time-series, pie, box-plots, heatmap, trends) |
| `models` | Trains Ridge, Random Forest, Gradient Boosting, XGBoost with 5-fold time-series CV |
| `forecast` | Rolls a 30-day AQI forecast using the best model |
| `shap` | Computes and plots SHAP feature importance |
| `summary` | Saves `summary.json` and `summary_report.txt` |

### 3. Run a single step

```bash
python HaleemaSadiya_hydaqi.py --step preprocess
python HaleemaSadiya_hydaqi.py --step eda
python HaleemaSadiya_hydaqi.py --step models
python HaleemaSadiya_hydaqi.py --step forecast
python HaleemaSadiya_hydaqi.py --step shap
python HaleemaSadiya_hydaqi.py --step summary
```

### 4. Launch the dashboard

```bash
streamlit run app/streamlit_app.py
```

Open `http://localhost:8501` in your browser.

## Dataset

| File | Source | Rows (approx.) |
|------|--------|----------------|
| `city_day.csv` | "Air Quality Data in India" by Rohan Rao (Kaggle) | ~29,000 (all cities) |
| `station_day.csv` | "Air Quality Data in India" by Rohan Rao (Kaggle) | ~430,000 (all stations) |

> Dataset link: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india

The pipeline filters rows where `City == "Hyderabad"`.

Columns: `Date`, `PM2.5`, `PM10`, `NO`, `NO2`, `NOx`, `NH3`, `CO`, `SO2`, `O3`, `Benzene`, `Toluene`, `Xylene`, `AQI`, `AQI_Bucket`.

---

## Models

Four regression models are trained and evaluated using 5-fold time-series cross-validation:

- **Ridge Regression** — regularised linear baseline
- **Random Forest** — 200 trees, max depth 10
- **XGBoost** — 300 estimators, lr=0.05
- **Gradient Boosting** — sklearn GBM, 200 estimators

Metrics reported: RMSE, MAE, R².
